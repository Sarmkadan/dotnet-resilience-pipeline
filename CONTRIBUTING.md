# Contributing to DotNet Resilience Pipeline

Thank you for your interest in contributing! Here's how you can help.

## Development Requirements
- **.NET SDK:** Ensure you have the .NET 10.0 SDK installed.

## Getting Started
1. **Fork** the repository on GitHub.
2. **Clone** your fork locally: `git clone https://github.com/your-username/dotnet-resilience-pipeline.git`
3. **Create a branch** for your feature or bug fix: `git checkout -b feature/your-feature-name`
4. **Make your changes**.

## Running Tests
Ensure all existing and new tests pass before submitting your changes. You can run tests using the .NET CLI:
```bash
dotnet test
```

## Submitting a Pull Request
Once you're ready, push your branch to your fork and submit a Pull Request (PR) against the main repository. Please provide a clear description of your changes and any relevant issue numbers.

## Code Style
- Follow the existing coding conventions and style within the repository.
- Ensure all public APIs have appropriate XML documentation comments.
- **Keep all author headers** intact - DO NOT remove them from existing files.

## Reporting Issues
If you find a bug or have a feature request, please open an issue using GitHub Issues. Make sure to include detailed reproduction steps for bugs.
