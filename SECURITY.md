# Security Policy

We take the security of this project seriously. 

## Supported Versions

Currently, the following versions are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please follow these steps to report it safely:

1. **GitHub Private Advisory:** Please use GitHub's built-in private advisory feature to report the vulnerability securely.
2. **Email:** Alternatively, you can contact the maintainer directly at rutova2@gmail.com.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to resolve the issue promptly.
