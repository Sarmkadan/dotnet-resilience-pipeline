# FailureInjectionServiceTests

The `FailureInjectionServiceTests` class contains unit tests for validating the behavior of a failure injection service within the `dotnet-resilience-pipeline` project. This service is designed to simulate faults (e.g., exceptions, latency) during execution to test the resilience of dependent operations. The tests verify that the service correctly applies or bypasses fault injection based on configured rules, injection rates, and activation states.

## API

### `ExecuteAsync_NoRuleRegistered_RunsOperationNormally`
**Purpose**: Verifies that an operation executes normally when no failure injection rules are registered.
**Parameters**: None.
**Return Value**: A `Task` representing the asynchronous operation.
**Throws**: Does not throw under normal conditions.

### `ExecuteAsync_ExceptionRule_ThrowsInjectedFault`
**Purpose**: Ensures that the service throws an injected exception when an exception-based rule is registered and active.
**Parameters**: None.
**Return Value**: A `Task` representing the asynchronous operation.
**Throws**: The injected exception as specified by the rule.

### `ExecuteAsync_LatencyRule_AddsDelayAndReturnsResult`
**Purpose**: Confirms that the service introduces a delay when a latency-based rule is registered and active, but still returns the expected result.
**Parameters**: None.
**Return Value**: A `Task` representing the asynchronous operation.
**Throws**: Does not throw under normal conditions.

### `ExecuteAsync_DisabledRule_RunsOperationNormally`
**Purpose**: Validates that an operation executes normally when a registered rule is disabled.
**Parameters**: None.
**Return Value**: A `Task` representing the asynchronous operation.
**Throws**: Does not throw under normal conditions.

### `ExecuteAsync_ZeroInjectionRate_NeverInjects`
**Purpose**: Tests that no faults are injected when the injection rate is set to zero, even if a rule is registered.
**Parameters**: None.
**Return Value**: A `Task` representing the asynchronous operation.
**Throws**: Does not throw under normal conditions.

### `TotalInjections_IncrementsOnEachInjectedCall`
**Purpose**: Ensures that the `TotalInjections` counter increments each time a fault is injected.
**Parameters**: None.
**Return Value**: A `Task` representing the asynchronous operation.
**Throws**: Does not throw under normal conditions.

### `ExceptionFactory_UsedWhenProvided`
**Purpose**: Verifies that a custom exception factory is used to generate the injected exception when provided.
**Parameters**: None.
**Return Value**: A `Task` representing the asynchronous operation.
**Throws**: The exception generated by the custom factory.

### `DisableAll_DeactivatesAllRules`
**Purpose**: Confirms that calling `DisableAll` deactivates all registered rules, causing operations to execute normally.
**Parameters**: None.
**Return Value**: Void.
**Throws**: Does not throw under normal conditions.

### `RemoveRule_ExistingKey_ReturnsTrueAndRuleIsGone`
**Purpose**: Tests that removing a rule with an existing key returns `true` and the rule is no longer active.
**Parameters**: None.
**Return Value**: Void.
**Throws**: Does not throw under normal conditions.
