# Policy JSON extensions

This page describes six JSON helper classes for resilience policies and the policy
snapshot. Each class exposes extension methods that serialize one type with
`System.Text.Json`. For the general pattern (serializing an instance, calling the
helper class directly to deserialize, and the nullable contract) see
[json-extensions.md](json-extensions.md). This page does not repeat that material.

> **Status: these files are not in the current tree.**
> `RetryPolicyJsonExtensions.cs`, `CircuitBreakerPolicyJsonExtensions.cs`,
> `TimeoutPolicyJsonExtensions.cs`, `BulkheadPolicyJsonExtensions.cs`,
> `AdaptiveTimeoutPolicyJsonExtensions.cs`, and `PolicySnapshotJsonExtensions.cs`
> were removed from `src/Domain/Policies/` in commit `bbd0df8`
> (`fix: remove junk JsonExtensions files generated by engines`). The signatures,
> behavior, and samples below come from the last committed versions, which are
> available at `bbd0df8^`. Do not reference these helpers from new code until they
> are restored or replaced. [json-extensions.md](json-extensions.md) still lists
> `BulkheadPolicyJsonExtensions` as an available helper; that entry is out of date.

Sample JSON below is hand-written from each helper's projection and the default
property values in the policy classes. It is not captured program output. Values
are illustrative and `id` values are placeholders.

## Common conventions

- Namespace for all six helpers: `DotNetResiliencePipeline.Domain.Policies`.
- Target types are `RetryPolicy`, `CircuitBreakerPolicy`, `TimeoutPolicy`,
  `BulkheadPolicy`, `AdaptiveTimeoutPolicy`, and `PolicySnapshot`. All live in the same namespace.
- Only `BulkheadPolicyJsonExtensions` provides `FromJson` and `TryFromJson`. The other
  five helpers are serialization-only.
- `ToJson` on `RetryPolicy`, `CircuitBreakerPolicy`, `TimeoutPolicy`, and
  `AdaptiveTimeoutPolicy` takes no `indented` parameter and always writes compact JSON.
- `ArgumentNullException` is thrown when the target is `null`. The exception is
  `ArgumentNullException.ThrowIfNull`, which the helpers call first.
- `TimeSpan` values are written as `"hh:mm:ss"` or `"hh:mm:ss.fffffff"` strings.

## RetryPolicyJsonExtensions

Serializes a projection of `RetryPolicy` configuration and counters. It does not
serialize the `RetryableExceptions` types themselves. It writes each type's `Name`.

```csharp
public static class RetryPolicyJsonExtensions
{
    public static string ToJson(this RetryPolicy policy);
}
```

- Options: `JsonSerializerDefaults.Web` (camelCase), created per call.
- `Strategy` is written as the enum name (`ToString()`).
- Excludes `Tags`, `Metadata`, and the timestamps from the base class.

Sample output (defaults, one retryable exception):

```json
{"id":"0b6e4f1a-2c7d-4e8f-9a3b-5d1c2e7f8a90","name":"default-retry","isEnabled":true,"maxRetries":3,"initialDelay":"00:00:00.1000000","maxDelay":"00:00:30","strategy":"Exponential","backoffMultiplier":2,"useJitter":true,"jitterFactor":1,"useDecorrelatedJitter":false,"retryableExceptions":["HttpRequestException"],"totalExecutions":10,"successfulExecutions":8,"failedExecutions":2,"totalRetryAttempts":4}
```

## CircuitBreakerPolicyJsonExtensions

Serializes circuit breaker configuration, current state, and counters.

```csharp
public static class CircuitBreakerPolicyJsonExtensions
{
    public static string ToJson(this CircuitBreakerPolicy policy);
}
```

- Options: `JsonSerializerDefaults.Web` (camelCase), created per call.
- `state` is `policy.CurrentState.ToString()`, one of `Closed`, `Open`, or `HalfOpen`.
- Includes `consecutiveFailures` and `circuitBreakerTrips`.

Sample output (defaults, closed circuit):

```json
{"id":"7a1d3c5e-8b2f-4a6d-b0e9-1f2c3d4e5f60","name":"default-breaker","isEnabled":true,"failureThreshold":5,"openDuration":"00:00:30","state":"Closed","totalExecutions":12,"successfulExecutions":11,"failedExecutions":1,"consecutiveFailures":0,"circuitBreakerTrips":0}
```

## TimeoutPolicyJsonExtensions

Serializes timeout configuration and execution-time statistics.

```csharp
public static class TimeoutPolicyJsonExtensions
{
    public static string ToJson(this TimeoutPolicy policy);
}
```

- Options: `JsonSerializerDefaults.Web` (camelCase), created per call.
- `shortestExecutionTimeMs` starts at `long.MaxValue` (9223372036854775807) until
  the first execution is recorded. Treat that value as "no data".

Sample output (defaults, no executions yet):

```json
{"id":"c4e8a2d0-1b3f-4c5e-8d7a-9f0e1b2c3d4e","name":"default-timeout","isEnabled":true,"timeout":"00:00:10","totalExecutions":0,"successfulExecutions":0,"failedExecutions":0,"timeoutCount":0,"averageExecutionTimeMs":0,"longestExecutionTimeMs":0,"shortestExecutionTimeMs":9223372036854775807}
```

## BulkheadPolicyJsonExtensions

Round-trips a `BulkheadPolicy`. This is the only helper in this set with a
deserializer.

```csharp
public static class BulkheadPolicyJsonExtensions
{
    public static string ToJson(this BulkheadPolicy value, bool indented = false);
    public static BulkheadPolicy? FromJson(string json);
    public static bool TryFromJson(string json, out BulkheadPolicy? value);
}
```

- `ToJson` serializes the whole object, not a projection. Every public readable
  property is written. The `indented` flag switches `WriteIndented` on or off.
- Options: `JsonSerializerDefaults.Web`, `CamelCase` naming, `ReferenceHandler.IgnoreCycles`,
  and `DefaultJsonTypeInfoResolver`. The options are a `static readonly` field.
- `FromJson` returns `null` for a null, empty, or whitespace-only string. It throws
  `JsonException` for malformed JSON.
- `TryFromJson` returns `false` for a null, empty, or whitespace-only string, and
  for malformed JSON. It returns `true` with `value == null` if the input is the
  literal `null`.
- Round-trip has not been verified against the current `BulkheadPolicy` shape.
  Check it before relying on it.

Sample output (abbreviated, defaults; the real output includes all public
properties of `BulkheadPolicy`):

```json
{"id":"e9f0a1b2-3c4d-4e5f-8a6b-7c8d9e0f1a2b","name":"default-bulkhead","isEnabled":true,"maxParallelization":10,"maxQueueLength":50,"maxQueueWaitTimeout":"00:00:30","rejectedCount":0,"queuedCount":0,"averageQueueTimeMs":0,"longestQueueTimeMs":0}
```

## AdaptiveTimeoutPolicyJsonExtensions

Serializes adaptive timeout configuration, the current computed timeout, and counters.

```csharp
public static class AdaptiveTimeoutPolicyJsonExtensions
{
    public static string ToJson(this AdaptiveTimeoutPolicy policy);
}
```

- Options: default `JsonSerializerOptions`, so property names keep their C#
  PascalCase. This differs from the other helpers, which use camelCase.
- `TargetPercentile` is in percent (default `95`).
- Output is compact.

Sample output (defaults):

```json
{"Id":"2d4f6a8c-0e1b-4d3f-9a5c-7b9d1e3f5a7c","Name":"default-adaptive","IsEnabled":true,"InitialTimeout":"00:00:10","MinTimeout":"00:00:00.2000000","MaxTimeout":"00:01:00","CurrentTimeout":"00:00:10","TargetPercentile":95,"WindowSize":100,"MinSampleSize":10,"TotalExecutions":0,"SuccessfulExecutions":0,"FailedExecutions":0,"TotalAdjustments":0,"TimeoutCount":0}
```

## PolicySnapshotJsonExtensions

Serializes a `PolicySnapshot`, the reporting view of a policy's state. Options are
the library's shared `JsonSerializerOptionsProvider.SharedOptions`, which is
`internal` in `DotNetResiliencePipeline.Utilities`.

```csharp
public static class PolicySnapshotJsonExtensions
{
    public static string ToJson(this PolicySnapshot snapshot);
}
```

- Options: `JsonSerializerDefaults.Web`, `WhenWritingNull` ignore, `IgnoreCycles`, and
  enums as camelCase strings.
- Null properties are omitted. In practice that means `metadata` is absent
  when it is `null`.
- `snapshotTime` is an ISO 8601 `DateTime` string.

Sample output (metadata absent):

```json
{"policyId":"0b6e4f1a-2c7d-4e8f-9a3b-5d1c2e7f8a90","policyName":"default-retry","policyType":"Retry","isEnabled":true,"totalExecutions":10,"successfulExecutions":8,"failedExecutions":2,"successRate":0.8,"snapshotTime":"2026-10-25T12:00:00Z"}
```
