# ExecutionRecordExtensions

Groups the helper methods that operate on `ExecutionRecord` instances, which are stored in `ExecutionHistoryRepository` and produced by the resilience policies. The helpers live in three files under `src/Data/`:

- `ExecutionRecordEnumerableExtensions.cs` — aggregate calculations over a sequence of records.
- `ExecutionRecordJsonExtensions.cs` — **not present in the repository** (see the note in its section below).
- `ExecutionRecordValidation.cs` — validation of a single record.

All methods are `public static` extension methods in the `DotNetResiliencePipeline.Data` namespace.

## ExecutionRecordEnumerableExtensions

Source: `src/Data/ExecutionRecordEnumerableExtensions.cs`

Extension methods for `IEnumerable<ExecutionRecord>`.

### SuccessRate

```csharp
public static double SuccessRate(this IEnumerable<ExecutionRecord> records)
```

Calculates the percentage of records whose `IsSuccess` is `true`. The sequence is enumerated once, so a lazy query is executed when this method is called.

**Parameters:**
- `records` — The execution records to evaluate.

**Return Value:** The percentage of successful records, from `0` to `100`. Returns `0` when the sequence is empty.

**Throws:** `ArgumentNullException` if `records` is `null`.

#### Example

```csharp
var records = new List<ExecutionRecord>
{
    new() { PolicyName = "Retry", IsSuccess = true },
    new() { PolicyName = "Retry", IsSuccess = true },
    new() { PolicyName = "Retry", IsSuccess = false }
};

double rate = records.SuccessRate();   // 66.666...

double none = new List<ExecutionRecord>().SuccessRate();   // 0
```

## ExecutionRecordValidation

Source: `src/Data/ExecutionRecordValidation.cs`

Validation helpers for a single `ExecutionRecord`. All three methods are extensions on `ExecutionRecord`; `IsValid` accepts a nullable receiver.

### Validate

```csharp
public static IReadOnlyList<string> Validate(this ExecutionRecord value)
```

Checks the record against all rules and returns every problem found, not just the first. Each message is a human-readable sentence.

**Parameters:**
- `value` — The execution record to validate.

**Return Value:** A read-only list of validation problems, or an empty list if the record is valid.

**Throws:** `ArgumentNullException` if `value` is `null`.

The rules are:

| Property | Rule | Message |
|---|---|---|
| `ExecutionId` | Must not be null, empty or whitespace | `Execution ID cannot be null or whitespace.` |
| `ExecutionId` | Must parse as a GUID (when not blank) | `Execution ID must be a valid GUID.` |
| `PolicyName` | Must not be null, empty or whitespace | `Policy name cannot be null or whitespace.` |
| `PolicyId` | Must not be null, empty or whitespace | `Policy ID cannot be null or whitespace.` |
| `ExecutionTimeMs` | Must not be negative | `Execution time (ms) cannot be negative.` |
| `AttemptCount` | Must not be negative | `Attempt count cannot be negative.` |
| `ExecutedAt` | Must not equal `default` (Unix epoch) | `Executed at timestamp cannot be default (Unix epoch).` |
| `ExecutedAt` | Must not be more than 5 minutes in the future (UTC) | `Executed at timestamp cannot be in the future.` |
| `Metadata` | Must not be `null` | `Metadata dictionary cannot be null.` |
| `ErrorMessage` | At most 10,000 characters when set | `Error message cannot exceed 10,000 characters.` |
| `ErrorType` | At most 500 characters when set | `Error type cannot exceed 500 characters.` |

#### Example

```csharp
var record = new ExecutionRecord
{
    ExecutionId = "not-a-guid",
    PolicyName = "",
    PolicyId = "retry-default",
    ExecutionTimeMs = -5,
    ExecutedAt = DateTime.UtcNow
};

IReadOnlyList<string> problems = record.Validate();

// problems[0] == "Execution ID must be a valid GUID."
// problems[1] == "Policy name cannot be null or whitespace."
// problems[2] == "Execution time (ms) cannot be negative."
```

### IsValid

```csharp
public static bool IsValid(this ExecutionRecord? value)
```

Returns `true` when `value.Validate()` finds no problems.

**Parameters:**
- `value` — The execution record to check. May be `null`.

**Return Value:** `true` if the record is valid; otherwise `false`. A `null` record returns `false`.

**Throws:** Nothing. Passing `null` does not throw.

> **Note:** The XML documentation on this method in `ExecutionRecordValidation.cs` states that it throws `ArgumentNullException`. The implementation does not: it evaluates `value?.Validate().Count == 0`, which yields `false` for `null`. This document describes the implemented behavior.

#### Example

```csharp
var record = new ExecutionRecord
{
    ExecutionId = Guid.NewGuid().ToString(),
    PolicyName = "Retry",
    PolicyId = "retry-default"
};

bool ok = record.IsValid();          // true

ExecutionRecord? missing = null;
bool none = missing.IsValid();       // false, no exception
```

### EnsureValid

```csharp
public static void EnsureValid(this ExecutionRecord value)
```

Throws if the record fails any rule in `Validate`. Use it at boundaries where an invalid record must not continue, such as before it is persisted.

**Parameters:**
- `value` — The execution record to validate.

**Throws:**
- `ArgumentNullException` if `value` is `null`.
- `ArgumentException` if the record has one or more validation problems. The exception's message starts with `Execution record is invalid. Problems:` and lists each problem on its own line. `ParamName` is `"value"`.

#### Example

```csharp
try
{
    record.EnsureValid();
    repository.Add(record);
}
catch (ArgumentException ex)
{
    logger.LogWarning(ex, "Rejected invalid execution record {ExecutionId}", record.ExecutionId);
}
```
